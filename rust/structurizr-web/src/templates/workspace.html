Interacting with the diagram
  • Drag the background to pan; ctrl/⌘ + scroll (or pinch) to zoom.
  • Double-click an element to drill in — look for the magnifying glass.
  • Hover an element or relationship for details.
  • Click an element or relationship to select it; shift-click adds to the selection, and Esc or a click on the background clears it. The page URL always links to the selection — structurizrx locate finds it in the DSL — and the status bar links each selected item to its declaration in VS Code.
  • + - zoom in/out, c fit content, w fit width, h fit height
  • ← → previous/next view · space or ⌘K find a view, element, decision or command
  • [ show or hide the view list
  • d toggle descriptions · m toggle metadata · t toggle tooltips
  • , . step through animation · i diagram key
  • f full screen · p print this view · ? this help
